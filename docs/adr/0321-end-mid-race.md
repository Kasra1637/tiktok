# ADR 0321: End mid-race

Status: accepted

## Context

The founder's own Hook + CTA hook — "I'm trying to name
this tight feeling and it keeps slipping away" — rated
7/10 against the tightened rewrite Flash offered, "I'm
trying to name this tight feeling before it slips away",
at 8/10 (Nov 24 2026). The whole gap was the ending: his
line closed by announcing the loss as settled fact, the
rewrite kept the race live. He then ordered the generator
optimized so hooks land at that level by default — his
own exception to the standing stop-tuning settlement,
called the same way as ADR 0316's instruction — and
added the handoff half himself: the line must end so the
demo can continue immediately, on the very next beat.

## Decision

The shared spoken-line rules' HOOK POWER bullet gains
END MID-RACE, NOT ON THE VERDICT, beside WITHHOLD THE
RESOLUTION: never close the hook by announcing the loss
as settled fact ("and it keeps slipping away" reports
the feeling already gone, and the story is over before
the demo can start); end with the attempt still live
against the loss ("before it slips away"), the catch
undecided, so the demo starts on the very next beat and
lands as the catch. Both hook surfaces inherit it — the
block is shared by the plan, the strategy and the
Hook + CTA hook writer. Redundant phrasing elsewhere in
the block (a goal-rule restatement, the payoff-echo
sentence the extension bullet already carries, a
same-moment tail compressed) was trimmed to pay for it
under the strategy prompt's 48,600 ceiling, which binds
unchanged.

## Consequences

Generated hooks stop ending on the verdict — the flat
stated loss that cost the founder's hook its point — and
end instead on the live race the demo wins. The honest
limit stands, stated to the founder when he ordered it:
this raises the floor, it cannot guarantee every
generation an 8; the rewrite remains the last notch.
