# ADR 0305: The silent note is one short line

Status: accepted

## Context

On the Hook + CTA page, picking "Character stays silent" shows
the note that tells the founder what silence means and what to
paste into TikTok's text-to-speech. The note ran long — two
sentences plus the line to paste set on its own line below —
and its placeholder trailed off into a second clause ("that
exact text is the one to paste"), so the block read as broken,
unfinished text. The founder ordered it fixed twice in one
evening (Nov 23 2026): make the line shorter, no line break —
and fix the incomplete, broken wording across it. A punchier
draft of this note had been offered on Nov 22 2026 and never
built; the long copy stayed live meanwhile.

## Decision

The note is one short paragraph with the line to paste inline
in the same run of text — no block span, no break before it:
"The character stays silent in this video — no voice, and the
mouth never moves. For a voice on TikTok, paste this line into
TikTok's text-to-speech: " followed by the hook line in quotes
when one exists, or the completed placeholder "The hook line
will appear here once it is written." The trailing clause is
gone; every sentence in the note is complete.

## Consequences

The Voice section reads as one clean instruction, and the line
to paste is identifiable at a glance by its quotes and weight.
The note's jest expectations move with the copy; nothing else
about the voice pick changes.
