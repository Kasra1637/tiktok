Demo + CTA visual assets
========================

Vendored into this repository so the editor's required inputs do not depend on a
third-party request at render time. The hand plate is keyed per pixel and the
Anton face is painted onto a canvas, so a blocked or slow remote fetch degrades
an export rather than just a page.

hand.jpg
  Woman's arm / wrist / hand holding a modern black phone, shot on a seamless
  white studio backdrop so the backdrop can be keyed out cleanly.

Each file is the unmodified original response. Resizing, re-encoding or
re-keying them changes the composite: the screen-rectangle defaults in
src/demoCta/handView.js are measured against the exact hand.jpg dimensions.
